# IRMA-X WEB · GitHub Pages · edición gratuita

## Publicación (sin instalar Python)
1. Extrae el ZIP en tu computadora.
2. Crea un repositorio público nuevo en GitHub, por ejemplo `IRMA-X-WEB`.
3. En la página del repositorio elige **Add file > Upload files**.
4. Sube `index.html` y `README.md` **directamente a la raíz** del repositorio, no la carpeta ni el ZIP.
5. Pulsa **Commit changes**.
6. Ve a **Settings > Pages**; en **Build and deployment**, selecciona **Deploy from a branch**, `main`, `/(root)` y **Save**.
7. La dirección será `https://TU-USUARIO.github.io/IRMA-X-WEB/` cuando GitHub termine la publicación.

## Incluido
- Interfaz oscura adaptable a celulares, menú, robot asistente local basado en reglas.
- 18 campos de pozo, almacenamiento local por navegador, importación y exportación JSON.
- Motor IPR JavaScript: Vogel (petróleo saturado), lineal monofásico y contrapresión empírica para gas seco, con verificaciones básicas y CSV.
- Panel IPR/VLP demostrativo: **VLP algebraica ilustrativa no validada**, no usar para decisiones de campo.
- Biblioteca de enlaces externos, matriz de recuperación preliminar, modelo 3D conceptual y resumen HTML.

## NO incluido (evitar falsas expectativas)
- IA generativa real, RAG o documentos indexados.
- Base de datos centralizada ni sincronización entre dispositivos.
- VLP multifásica física validada, diseño de fracturas, simulación dinámica EOR, optimización de campo.
- Acceso automático a bases de datos privadas o comerciales.

Esta versión no tiene costos de licencias, no necesita Python, Ollama, cuentas ni servidor para funcionar. GitHub Pages es un servicio externo gratuito bajo sus términos y límites; el almacenamiento local depende del navegador. **No subas datos confidenciales a un repositorio público.**
